Unruly Labs LP · TikTok Content Posting API integration data-handling disclosure

Effective date: 2026-08-18
Last updated: 2026-08-18

This page describes data handling for the TikTok Content Posting API integration operated by Unruly Labs LP.

What data this integration touches

Video files and post captions/metadata created internally by Unruly Labs LP for its own content channels. This integration does not collect, store, or process personal data from TikTok users, viewers, or any third party.

Authentication data

TikTok API access tokens are stored securely and used solely to authorize posting to Unruly Labs LP's own account(s). No credentials are shared with or accessible to third parties.

Data retention

Video files and associated metadata are retained only as long as needed for the operator's own content pipeline and are not sold, shared, or used for any purpose beyond posting to Unruly Labs LP's own channels.
