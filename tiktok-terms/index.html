This page covers the TikTok Content Posting API integration operated by Unruly Labs LP for its own content channels (including Unruly Scroll).

What this integration does

Unruly Labs LP uses TikTok's official Content Posting API to publish video content to accounts it owns and operates. This is an internal automation tool — it does not offer posting services to third parties, does not accept content from outside users, and has no public-facing sign-up or login.

Acceptable use

All content posted through this integration is produced by Unruly Labs LP and complies with TikTok's Community Guidelines and Terms of Service.
